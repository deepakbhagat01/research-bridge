RESEARCHBRIDGE WEBSITE + INSTALLABLE MOBILE WEB APP

WHAT YOU HAVE
- Responsive premium-corporate website.
- Installable Progressive Web App (PWA): visitors can add it to their phone home screen.
- Contact options: enquiry form (opens a pre-filled email draft), email link, WhatsApp link.
- No paid hosting or database is required for this first version.

IMPORTANT
This is a PWA, not a native Android/iPhone app-store application. It gives users an app-like installed experience from the website. A native app would be a separate project.
The contact form does NOT send data to a server or store submissions. It opens the visitor's email app. For a true online form/inbox, connect a form provider or secure backend later.
The site currently contains sample email and WhatsApp details. Do not publish until you replace them with contact details approved and supervised by a parent/guardian.

EDIT CONTACT DETAILS
1. Open config.js in a text editor.
2. Replace YOUR_EMAIL@example.com with the approved email.
3. Replace 910000000000 with the WhatsApp number, digits only, including country code.
4. Save the file.

FREE PUBLISHING WITH GITHUB PAGES
1. A parent/guardian should supervise account creation and publishing, and check the current age and account rules for the service.
2. Sign in to GitHub and create a new public repository named researchbridge-website.
3. Extract this ZIP on your computer.
4. Upload all files and the assets folder from inside ResearchBridge_Website into the repository root. Do not upload the ZIP itself.
5. In the repository, open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Choose branch main and folder /(root), then Save.
8. Wait for the Pages deployment to finish. GitHub will show the public website address in Settings > Pages.
9. Open the link on a phone. In the browser menu choose Install app or Add to Home Screen (wording varies).

FREE PUBLISHING WITH NETLIFY (alternative)
1. A parent/guardian should supervise account creation and publishing and check current account rules.
2. Extract the ZIP.
3. Open Netlify and use its manual deploy / drag-and-drop option.
4. Drag the extracted ResearchBridge_Website folder (the folder containing index.html) into the deploy area.
5. Netlify will provide a public website URL. You can change the site name if available.
6. Open the URL on a phone and use Install app / Add to Home Screen if the browser offers it.
